# BULBA-UTILS
**Utilities for Bulbastore**  

Currently, there is only one feature available.  
Run the program and select "FETCH" to get the latest data from Bulbastore.  
Downloaded data is then saved to the "data" directory as a CSV file.  
Item data is then displayed, starting from least recently updated to the most recently updated.  
If there is an older snapshot (CSV file) available, any changes in stock are also displayed.
